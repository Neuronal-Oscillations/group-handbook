# How to set up the printers at OHBA and LaMB 
## Purpose
Here, you can find simple steps for printing at OxCIN locations. 

## Preparation 
You will need to download the iPrintClient application from this website: https://iprint.imsu.ox.ac.uk/ipp. 

Having downloaded iPrint Client, go back to the link above to set up individual printers: 

## LaMB

### Steps
1. Ctrl-F the followng printer: *Lamb-Follow_Me*, which would take you to any printer at the LaMB.
2. Install the printer
3. You may be asked to insert 1) Your laptop's password, 2) **Your MSD IT Username and Password** - please make note of these.
4. When printing for the first time, you may need to log into the printing system first. Go to a printer at the LaMB, press your BodCard on the corresponding field, and sign in with your MSD Username and Password.
5. When printing your document, select "Lamb_Follow_Me" under printer options.

More detailed instructions can be accessed here: https://unioxfordnexus.sharepoint.com/sites/XPSY-ExperimentalPsychology/HowTo%20Guides/Forms/AllItems.aspx?id=%2Fsites%2FXPSY%2DExperimentalPsychology%2FHowTo%20Guides%2FPrinting%2C%20Photocopying%20%26%20Scanning%20Instructions%5F2026%2Epdf&parent=%2Fsites%2FXPSY%2DExperimentalPsychology%2FHowTo%20Guides. 

## OHBA

### Steps
1. Ctrl-F the following printer: *PSYPRN36*, which is the printer located in the Psychiatry post room. 
2. Select the printer. If you see the message "The printer is not installed. Do you want to install it now?", click Yes.
3. Go to the file that you would like to print and select "Print"
4. When choosing a printer, select PSYCH_Admin_RICOHC5510_PSYPRN36
5. Monitor the job progress in iPrintClient
6. When your printing is done, pick it up from the Post Room
